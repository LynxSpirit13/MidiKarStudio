# MidiKar Studio

An Android-first MIDI/KAR creation and editing workstation.

## First milestone
- Native Android/Kotlin app scaffold
- GitHub Actions APK build workflow
- Initial project model and MIDI file inspection foundation
- Lyrics and Piano Roll tabs are planned; advanced editing and SoundFont playback are incremental milestones

## Build
Push this repository to GitHub. Open **Actions** and run **Android CI** (or push to `main`). Download the APK from the successful workflow run's artifacts.

## Current status
This is the initial scaffold, not a finished MIDI/KAR editor. The first build validates the Android project structure and establishes the foundation for the file engine.
